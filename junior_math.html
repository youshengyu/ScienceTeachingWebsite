第一題：數線與絕對值

已知數線上有 A、B 兩點，分別表示數字 -5 和 3。若 C 點在 A、B 之間，且 AC : BC = 2 : 1，請問 C 點所代表的數是多少？

解答

1. 計算 A、B 之間的距離：$|3 - (-5)| = 8$。

2. C 點將線段 AB 分成 2:1，表示 C 點到 A 的距離佔總距離的 $\frac{2}{3}$。

3. 計算 AC 的長度：$8 \times \frac{2}{3} = \frac{16}{3}$。

4. C 點的坐標為 A 點坐標加上 AC 的長度：$-5 + \frac{16}{3} = -\frac{15}{3} + \frac{16}{3} = \frac{1}{3}$。

答案： C 點代表的數是 $\frac{1}{3}$。

第二題：一元一次方程式

解方程式 $3(2x - 1) - 2(x + 4) = 5$。

解答

1. 展開括號：$6x - 3 - 2x - 8 = 5$。

2. 合併同類項：$(6x - 2x) + (-3 - 8) = 5$，得到 $4x - 11 = 5$。

3. 移項：$4x = 5 + 11$，$4x = 16$。

4. 求解 x：$x = \frac{16}{4} = 4$。

答案： $x = 4$。
